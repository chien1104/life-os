# Life OS 生活整理工具箱

打開 `index.html` 就能使用。資料只存在你自己的瀏覽器裡。

## 第一次放上 GitHub 並產生網址

1. 到 https://github.com 註冊帳號。
2. 打開 Claude Code（電腦版或 https://claude.ai/code），把這個資料夾交給它，然後說：
   「幫我把這個資料夾建立成 GitHub repository，並開啟 GitHub Pages。」
3. 完成後網址會像這樣：`https://你的帳號.github.io/life-os/`

之後要改 App，直接在 Claude Code 說要改什麼；推上 GitHub 後，網址會自動更新。
